# 🛒 Shopping Hub

OLX Pakistan style classifieds website — buy & sell across Pakistan.

## Features
- 🔐 User signup, login, logout
- 📢 Post ads with photos, price, category, city
- 🔍 Search + category + city filters
- 📍 71 Pakistan cities
- 📱 Mobile-friendly design
- 👤 My Ads management

## Run Locally
```bash
npm install
npm start
```
Open http://localhost:3000

## Deploy to Render (Free)
1. Push this folder to GitHub
2. Go to render.com → New → Web Service
3. Connect your GitHub repo
4. Build: `npm install`, Start: `npm start`
5. You get a public link like `https://shopping-hub.onrender.com`

## Deploy to Railway (Free)
1. Push to GitHub
2. railway.app → New Project → Deploy from GitHub
3. Done — public link generated automatically
